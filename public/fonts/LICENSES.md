# Licenças das fontes

Arquivos `.woff2` baixados do Google Fonts (subconjunto latino), servidos pelo
próprio site para evitar conexões com outros domínios antes do primeiro texto.
Todas sob a SIL Open Font License 1.1 — https://openfontlicense.org

| Arquivo                           | Família                 | Autor / fonte                                        |
| --------------------------------- | ----------------------- | ---------------------------------------------------- |
| `inter-latin.woff2`               | Inter (variável 400–700) | Rasmus Andersson — https://github.com/rsms/inter    |
| `jetbrains-mono-latin.woff2`      | JetBrains Mono (variável 400–500) | JetBrains — https://github.com/JetBrains/JetBrainsMono |
| `saira-condensed-600-latin.woff2` | Saira Condensed 600     | Omnibus-Type — https://github.com/Omnibus-Type/Saira |
| `saira-condensed-700-latin.woff2` | Saira Condensed 700     | Omnibus-Type — https://github.com/Omnibus-Type/Saira |

Para atualizar: baixe o CSS de `fonts.googleapis.com/css2?family=…` com um
User-Agent de navegador moderno e pegue as URLs do bloco `/* latin */`.
